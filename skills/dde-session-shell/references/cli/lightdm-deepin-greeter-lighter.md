# lightdm-deepin-greeter-lighter 命令参考

LightDM Deepin Greeter 的辅助程序，用于在登录过程中处理亮度调节初始化操作。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-session-shell` |
| 安装路径 | `/usr/bin/lightdm-deepin-greeter-lighter` |
| DDE 角色 | 登录界面的亮度初始化辅助程序 |

## 用途

LightDM Deepin Greeter 的辅助程序，用于在登录过程中处理亮度调节初始化操作。它在 greeter 启动阶段运行，配合主 greeter 完成登录环境准备，不提供命令行参数。
