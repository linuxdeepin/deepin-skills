# lightdm-deepin-greeter 命令参考

DDE 登录界面（LightDM Greeter），是 deepin 定制的 LightDM 欢迎程序。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-session-shell` |
| 安装路径 | `/usr/bin/lightdm-deepin-greeter` |
| DDE 角色 | LightDM 登录管理器的 deepin 欢迎界面 |

## 用途

DDE 登录界面（LightDM Greeter），是 deepin 定制的 LightDM 欢迎程序。它在系统登录阶段显示登录界面，处理用户认证、会话选择和登录流程，是 DDE 登录管理的核心组件。该程序由 LightDM 在登录阶段自动启动，不提供命令行参数。
