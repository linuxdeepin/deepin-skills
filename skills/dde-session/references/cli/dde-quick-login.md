# dde-quick-login 命令参考

DDE 锁屏快速登录工具，用于在锁屏状态下快速重新登录。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-session` |
| 安装路径 | `/usr/bin/dde-quick-login` |
| DDE 角色 | 系统调用的辅助工具，锁屏场景下自动调用 |

## 用途

DDE 锁屏快速登录工具，用于在锁屏状态下快速重新登录。当系统处于锁屏状态时，该工具可以在超时时间内尝试自动重新登录，常用于系统唤醒后快速恢复桌面会话的场景。通过 `-t` 参数可以指定超时时间，超时后自动放弃登录尝试。该工具通常由系统在特定场景下自动调用。

## 用法

`dde-quick-login [options]`

## 参数

| 选项 | 说明 | 是否需要值 |
|------|------|------------|
| `-h, --help` | 显示命令行帮助 | 否 |
| `-v, --version` | 显示版本信息 | 否 |
| `-t <timeout>` | 超时时间（秒） | 是 |

## 使用示例

```bash
# 默认快速登录（使用默认超时时间）
dde-quick-login

# 指定超时时间为 5 秒
dde-quick-login -t 5

# 指定超时时间为 30 秒
dde-quick-login -t 30

# 查看版本信息
dde-quick-login -v
# 输出示例：
# dde-quick-login version 1.0
```
