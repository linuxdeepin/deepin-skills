# org.deepin.ds.dock QML 模块

该文件涵盖两个 QML 模块：`org.deepin.ds.dock` 提供 Dock 面板枚举命名空间和 Dock 定位附加属性，`org.deepin.ds.dock.tray` 提供托盘区域排序与定位管理接口。用于 Dock 面板及 Dock 区域插件获取 Dock 位置信息、控制窗口定位以及管理托盘项的排序、位置和可见性。

## 集成

### 使用方式

Dock 面板 QML 模块 URI 为 `org.deepin.ds.dock`，导入版本为 `1.0`；托盘区域 QML 模块 URI 为 `org.deepin.ds.dock.tray`，导入版本为 `1.0`。这两个模块由 dde-shell Dock 运行时提供，使用方无需安装额外的 QML 模块包。在 QML 文件中通过以下方式导入：

```qml
import org.deepin.ds.dock 1.0
import org.deepin.ds.dock.tray 1.0
```

导入 `org.deepin.ds.dock` 后可使用 `Dock`、`DockPositioner`、`DockPanelPositioner`、`AppletDockItem` 类型，其中 `Dock` 为枚举命名空间，`DockPositioner` 和 `DockPanelPositioner` 为附加属性类型。导入 `org.deepin.ds.dock.tray` 后可使用 `TraySortOrderModel`、`TrayItemPositionManager`、`TrayItemPositionRegister`、`SortFilterProxyModel`、`dropIndex` 类型，其中 `TraySortOrderModel` 和 `TrayItemPositionManager` 为单例对象，`TrayItemPositionRegister` 为附加属性类型，`dropIndex` 为结构体类型。

## 模块API介绍

### Dock

#### 定位

Dock 枚举命名空间，不可实例化。提供 Dock 面板的位置、隐藏模式、隐藏状态、指示器样式、项对齐方式、颜色主题、尺寸、动画动作、托盘弹窗类型、托盘插件类型、托盘插件尺寸策略和溢出状态共十二种枚举值。

#### 功能能力总结

- 定义 Dock 面板的屏幕位置（顶部、右侧、底部、左侧）和隐藏行为模式（一直显示、一直隐藏、智能隐藏），以及隐藏状态（显示、隐藏、未知），供插件根据 Dock 的实际位置和显示状态调整布局
- 定义指示器样式（时尚模式、高效模式）、项对齐方式（居中、左对齐、时尚对齐）和颜色主题（浅色、深色），使插件能够适配 Dock 的视觉风格
- 定义 Dock 尺寸常量（最小、默认、最大 Dock 尺寸及任务栏图标尺寸范围），为插件提供统一的尺寸约束参考
- 定义动画动作（显示、隐藏）、托盘弹窗类型（面板、提示、菜单、嵌入、子弹窗）、托盘插件类型（托盘、固定、快捷、卡片）、托盘插件尺寸策略（跟随系统、自定义）和溢出状态（无溢出、有溢出、全部溢出）枚举，支持插件在不同交互场景下选择正确的行为模式

#### 使用场景

开发 Dock 区域插件时，引用 Dock 面板的位置、隐藏模式和尺寸三种枚举值进行布局和状态判断。

### DockPositioner

#### 定位

Dock 定位附加属性类型，不可实例化，通过附加属性使用。提供 Dock 面板内窗口的边界设置和坐标获取能力。

#### 功能能力总结

- 根据 Dock 面板在屏幕上的位置和指定的边界矩形，自动计算窗口应放置的 x 和 y 坐标，使 Dock 面板内的窗口能够正确贴边显示
- 支持设置窗口的边界矩形约束，定位器在该约束范围内计算最优窗口位置
- 在边界矩形或坐标发生变化时通过信号通知 QML 层，使窗口能够实时响应 Dock 位置变化

#### 使用场景

开发 Dock 面板内的窗口或控件时，需要根据 Dock 面板位置和边界进行窗口定位时使用。

### DockPanelPositioner

#### 定位

Dock 面板定位附加属性类型，继承自 DockPositioner，不可实例化，通过附加属性使用。在 DockPositioner 基础上增加水平和垂直偏移控制。

#### 功能能力总结

- 继承 DockPositioner 的边界设置和坐标计算能力，根据 Dock 面板位置和边界矩形自动计算窗口坐标
- 支持设置水平偏移量和垂直偏移量，在自动定位基础上对窗口位置进行微调，满足 Dock 面板窗口的精细布局需求
- 在偏移量变化时通过信号通知 QML 层，使窗口能够实时响应偏移调整

#### 使用场景

开发 Dock 面板窗口时，需要在 Dock 定位基础上微调窗口水平或垂直位置时使用。


### AppletDockItem

#### 定位

org.deepin.ds.dock 模块中通过 QML 文件导出的 Dock 项基类型，继承自 org.deepin.ds.AppletItem，为 Dock 区域中的插件项提供 Dock 专属属性和自动尺寸计算能力。

#### 功能能力总结

- 提供 Dock 排列顺序属性，使 Dock 框架能够按照指定顺序排列各 Dock 项，控制项在 Dock 区域中的显示位置
- 根据所属 Applet 的可见性和功能支持状态自动计算 Dock 项的可见状态，仅在 Applet 可见且功能受支持时才在 Dock 中显示
- 根据 Dock 面板的位置（顶部或底部为水平方向，左侧或右侧为垂直方向）自动判断是否使用纵向布局，使 Dock 项能够适配不同方向的 Dock 面板
- 根据 Dock 布局方向和 Dock 尺寸自动计算隐式宽度和隐式高度，在水平布局时根据 Dock 高度计算项高度，在纵向布局时根据 Dock 宽度计算项宽度，确保 Dock 项尺寸与 Dock 面板尺寸协调

#### 使用场景

Dock 插件开发中作为自定义 Dock 项的基类型，提供 Dock 布局所需的排列顺序控制和自动尺寸计算。

### TraySortOrderModel

#### 定位

托盘项排序模型单例，不可实例化，通过单例访问。管理 Dock 托盘区域和收纳区域中托盘项的排序、可见性和拖放操作。

#### 功能能力总结

- 维护 Dock 托盘区域和收纳区域中所有托盘项的排序顺序，支持在 Dock 托盘和收纳区域之间通过拖放操作移动托盘项，并通过 DConfig 持久化排序结果
- 管理托盘项的可见性状态，支持按 Surface ID 控制项在托盘区域和 Dock 区域中的显示与隐藏，实现收纳和展开的动态切换
- 追踪托盘的折叠状态和折叠动画过程中的过渡状态，以及可视项数量，为 QML 层提供布局计算所需的状态信息
- 支持暂存拖放位置用于拖拽预览，在拖拽过程中实时显示目标位置，并可提交或清除暂存状态，实现流畅的拖拽交互体验
- 提供可视索引与模型索引的双向转换能力，并跟踪当前可用的 Surface 列表，使 QML 层能够准确定位和操作目标项

#### 使用场景

开发 Dock 托盘区域插件时，需要管理托盘项的排序、可见性或处理拖放操作时使用。

### TrayItemPositionManager

#### 定位

托盘项位置管理单例，不可实例化，通过单例访问。计算和管理 Dock 托盘区域中各项的视觉尺寸和位置。

#### 功能能力总结

- 根据 Dock 的方向（水平或垂直）和高度，以及当前可视项数量，自动计算托盘区域的整体可视尺寸，为 Dock 面板的尺寸调整提供数据支持
- 为每个托盘项计算视觉尺寸和位置坐标，综合考虑单项视觉尺寸、项间距和项内边距，确保各项在托盘区域中均匀排列
- 支持托盘项注册自身的视觉尺寸，使管理器能够根据实际项尺寸进行差异化布局计算
- 提供基于坐标点的拖放索引查找能力，根据鼠标位置判断拖放目标项的索引和相对位置，支撑拖放交互的目标定位
- 提供布局健康检查机制，在布局异常时触发重新计算，并支持清除已注册的尺寸数据以重置布局状态

#### 使用场景

开发 Dock 托盘区域插件时，需要计算项的布局尺寸或处理拖放位置查找时使用。

### TrayItemPositionRegister

#### 定位

托盘项位置注册附加属性类型，通过附加属性使用。允许托盘项向位置管理器注册自身的 Surface ID、分区类型、可视索引和视觉尺寸，并获取计算后的视觉位置。

#### 功能能力总结

- 作为托盘项与位置管理器之间的注册桥梁，使托盘项能够通过附加属性声明自身的 Surface ID、所属分区类型、可视索引和视觉尺寸
- 接收位置管理器计算后的视觉位置坐标并暴露给 QML 层，使托盘项能够根据计算结果设置自身的布局位置
- 在注册信息或计算结果发生变化时通过信号通知 QML 层，使托盘项能够实时响应布局调整

#### 使用场景

开发 Dock 托盘区域插件项时，通过附加属性向 Dock 托盘位置管理器注册项的位置信息并获取布局坐标。

### SortFilterProxyModel

#### 定位

排序过滤代理模型，可实例化。提供基于角色名、过滤字符串和 JavaScript 回调函数的排序与过滤能力，作为 QAbstractItemModel 的代理使用。

#### 功能能力总结

- 在 QML 中对源模型进行灵活的排序控制，支持按角色名指定排序字段、设置升序或降序，以及指定排序列
- 提供多种过滤方式：通过过滤字符串配合过滤角色名进行简单匹配过滤，或通过 JavaScript 回调函数实现复杂的自定义行级和列级过滤逻辑
- 暴露顶层行数属性，使 QML 层能够直接绑定过滤后的行数
- 支持手动使过滤失效并重新计算，在自定义过滤条件变化时触发过滤更新

#### 使用场景

需要在 QML 中对模型进行自定义排序或过滤时使用，支持通过 JavaScript 回调实现高级过滤逻辑。

### dropIndex

#### 定位

拖放位置信息结构体，不可实例化，作为方法返回值使用。描述拖放操作的目标索引和相对位置。

#### 功能能力总结

- 描述拖放操作的目标位置信息，包括目标索引值、拖放位置是否落在某个项上、以及是否在该项之前，为拖放排序提供精确的位置判断

#### 使用场景

通过 TrayItemPositionManager 的 itemIndexByPoint 方法获取拖放目标位置时，读取返回的 dropIndex 信息。
