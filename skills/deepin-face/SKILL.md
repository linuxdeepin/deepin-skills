# deepin-face

deepin-face 是 DDE 的人脸识别组件，通过 System 总线提供人脸录入、验证、删除和重命名能力。该接口需要提权操作。

## D-Bus 接口

### 人脸识别

提供人脸录入、验证、删除和重命名能力。

详见 [org.deepin.dde.Authenticate1.Face.md](references/dbus/org.deepin.dde.Authenticate1.Face.md)
