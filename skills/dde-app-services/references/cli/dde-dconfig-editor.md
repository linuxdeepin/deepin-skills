# dde-dconfig-editor 命令参考

DDE 配置编辑器，提供图形化界面用于查看和修改 DConfig 配置项。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-dconfig-editor` |
| 安装路径 | `/usr/bin/dde-dconfig-editor` |
| DDE 角色 | DConfig 配置的可视化编辑工具 |

## 用途

DDE 配置编辑器，提供图形化界面用于查看和修改 DConfig 配置项。它是面向开发者和高级用户的配置管理工具，支持按应用、配置项浏览和编辑 DConfig 键值。该工具为独立包，需单独安装（包名 `dde-dconfig-editor`），不随 `dde-dconfig-daemon` 一起安装。该工具没有提供桌面快捷方式，一般由用户在终端中启动。
