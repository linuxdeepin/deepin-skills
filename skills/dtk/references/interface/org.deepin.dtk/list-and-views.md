# 列表与视图控件

列表与导航视图涵盖滚动视图、堆栈视图、滑动视图、列表项代理、排序过滤模型、标签页栏和页面指示器。

## ScrollView

### 定位

Qt Quick 滚动视图的 DTK 样式实现。

### 功能能力总结

在有限视口区域内展示超出可视范围的内容的滚动容器，自动在内容尺寸超过视口时显示滚动条。支持横向和纵向滚动、滚轮手势和键盘翻页，滚动条样式遵循 DTK 主题规范，适用于长列表、长文本两类内容浏览场景。

### 使用场景

内容区域需要滚动浏览时使用。

## StackView

### 定位

Qt Quick 堆叠视图的 DTK 样式实现。

### 功能能力总结

以栈结构管理多个页面层的导航容器，支持将新页面压入栈顶（push）和弹出当前页面（pop）操作，页面切换时自动播放滑入滑出过渡动画。适用于向导式多步骤流程或需要返回上一页的层级导航场景。

### 使用场景

需要实现页面导航栈时使用。

## SwipeView

### 定位

Qt Quick 滑动视图的 DTK 样式实现。

### 功能能力总结

以横向滑动方式在多个全屏页面间切换的导航容器，用户通过左右滑动手势或点击底部指示器切换当前页面。每次仅显示一个页面，滑动时带有平滑过渡效果，适用于引导页、图片浏览或分页设置三种场景。

### 使用场景

需要可滑动切换的分页视图时使用。

## ItemDelegate

### 定位

Qt Quick 列表项委托的 DTK 样式实现。

### 功能能力总结

为列表委托项提供 DTK 主题样式，支持指示器和背景的可见性控制、级联选中、内容流式布局和自定义内容组件。可根据选中状态动态切换文字颜色，并根据项目在列表中的索引和总数自动计算圆角方向，实现列表项之间的圆角连续效果。

### 使用场景

在列表视图中需要 DTK 风格委托项并支持级联选中、圆角控制时使用。

## ArrowListView

### 定位

带箭头指示的有限高度列表视图。

### 功能能力总结

在有限高度内展示列表内容，支持限制最大可见项数和设置单项高度，超出部分通过滚动箭头指示，内部列表视图可供外部直接访问和操作。

### 使用场景

需要在弹出菜单或下拉框中显示有限项数并带滚动指示时使用。

## SortFilterModel

### 定位

排序过滤代理模型。

### 功能能力总结

为列表模型提供排序和过滤能力，支持通过自定义比较逻辑对数据进行排序、通过自定义条件筛选可见数据项，并可在数据变化时触发重新排序和过滤。

### 使用场景

需要对列表模型进行排序和过滤时使用。

## TabBar

### 定位

Qt Quick 选项卡栏的 DTK 样式实现。

### 功能能力总结

横向排列多个标签页标题的容器栏，点击标签项切换到对应页面。支持标签的增删、拖拽排序和当前选中标签高亮，自动应用 DTK 主题色，通常与 SwipeView 或 StackLayout 配合实现标签页切换。

### 使用场景

需要标签页导航时使用。

## PageIndicator

### 定位

Qt Quick 页面指示器的 DTK 样式实现。

### 功能能力总结

以一行圆点形式展示当前页面位置和总页数的指示控件，当前页对应的圆点以高亮尺寸或主题色区分。通常置于 SwipeView 或分页列表底部，让用户直观了解当前所处的页面位置和剩余页数。

### 使用场景

在分页浏览场景中指示当前页面位置时使用。

## Container

### 定位

Qt Quick 容器的 DTK 样式实现。

### 功能能力总结

提供内容区域背景和边框样式的通用容器基类，自动应用 DTK 主题背景色、圆角和边框，并管理子项的布局排列。本身不直接使用，由 Frame、Pane 两种具体容器类型继承其外观和布局能力。

### 使用场景

作为自定义容器控件的样式基类使用。

## Control

### 定位

Qt Quick 控件的 DTK 样式实现。

### 功能能力总结

所有 DTK 可交互控件的抽象基类，统一定义背景、边框、圆角和焦点边框四种视觉外观属性，并管理控件的内边距和隐式尺寸。本身不直接实例化，由 Button、TextField 两种具体控件类型继承其样式框架。

### 使用场景

作为自定义控件的样式基类使用。

## DialogButtonBox

### 定位

Qt Quick 对话框按钮组的 DTK 样式实现。

### 功能能力总结

按平台惯例水平排列对话框底部按钮的容器，自动将按钮按 AcceptRole、RejectRole 两种标准角色分组排列。支持设置按钮对齐方式和标准按钮组合，点击任意按钮时发出对应的 accepted 或 rejected 信号，便于对话框统一处理确认和取消操作。

### 使用场景

在对话框底部放置标准按钮时使用。

## ScrollBar

### 定位

Qt Quick 滚动条的 DTK 样式实现。

### 功能能力总结

以滑块在轨道中移动的方式指示和调节内容滚动位置的交互控件，支持拖动滑块快速定位、点击轨道翻页和滚轮操作。可设置水平和垂直方向，自动根据内容与视口的比例计算滑块大小，外观遵循 DTK 主题样式。

### 使用场景

内容区域需要可交互滚动条时使用。

## ScrollIndicator

### 定位

Qt Quick 滚动指示器的 DTK 样式实现。

### 功能能力总结

以细线条形式指示当前滚动位置的轻量控件，相比 ScrollBar 不支持交互拖动，仅提供视觉指示。在内容可滚动时自动显示，不占用额外交互空间，适用于移动端或空间受限的滚动区域。

### 使用场景

在不需要交互滚动条仅提示可滚动时使用。

## 最小使用示例

Qt6/DTK6 的最小界面，使用当前运行时的 org.deepin.dtk 模块。窗口需由 Qt Quick 应用加载。

```qml
import QtQuick
import org.deepin.dtk 1.0 as D

D.ApplicationWindow {
    visible: true
    width: 360
    height: 240
    D.ScrollView {
        anchors.fill: parent
        ListView {
            model: ["第一项", "第二项", "第三项"]
            delegate: D.ItemDelegate {
                required property string modelData
                width: ListView.view.width
                text: modelData
            }
        }
    }
}
```
