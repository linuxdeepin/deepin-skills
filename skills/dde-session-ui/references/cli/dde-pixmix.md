# dde-pixmix 命令参考

DDE 壁纸混合工具，用于将多张壁纸图片进行混合处理，输出适合当前桌面环境使用的背景图片。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-session-ui` |
| 安装路径 | `/usr/bin/dde-pixmix` |
| DDE 角色 | 系统调用的壁纸处理辅助工具 |

## 用途

DDE 壁纸混合工具，用于将多张壁纸图片进行混合处理，输出适合当前桌面环境使用的背景图片。它根据桌面分辨率和显示配置，对壁纸进行裁剪、缩放和混合，生成适配多显示器或不同分辨率场景的背景图。通过 `-o` 参数指定输出路径。该工具通常在用户更换壁纸或显示配置变更时由系统自动调用。

## 用法

`dde-pixmix [options]`

## 参数

| 选项 | 说明 | 是否需要值 |
|------|------|------------|
| `-h, --help` | 显示命令行帮助 | 否 |
| `-v, --version` | 显示版本信息 | 否 |
| `-o, --output <path>` | 输出适合的背景图片路径 | 是 |

## 使用示例

```bash
# 生成适合的背景图片到指定路径
dde-pixmix -o /home/user/.cache/deepin/wallpaper-mixed.jpg

# 查看版本信息
dde-pixmix -v
```

> 注意：`dde-pixmix` 是图形化壁纸处理工具，需要图形显示环境（X11/Wayland），在无 DISPLAY 的终端中运行会失败。
