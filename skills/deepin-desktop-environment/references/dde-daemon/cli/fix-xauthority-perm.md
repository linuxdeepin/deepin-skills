# fix-xauthority-perm 命令参考

Xauthority 权限修复工具，用于修正 `.Xauthority` 文件的权限问题。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-daemon` |
| 安装路径 | `/usr/lib/deepin-daemon/fix-xauthority-perm` |
| DDE 角色 | 会话启动阶段的 X 认证文件权限修复工具 |

## 用途

Xauthority 权限修复工具，用于修正 `.Xauthority` 文件的权限问题。它是一个辅助维护工具，在会话启动过程中确保 X 认证文件权限正确，不提供 flag 参数。
