# dde-pixmix 命令参考

壁纸色调处理工具，对输入壁纸图片计算平均色调并叠加半透明着色层，生成适合桌面环境的背景图片。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-session-ui` |
| 安装路径 | `/usr/bin/dde-pixmix` |
| DDE 角色 | 系统调用的壁纸处理辅助工具 |

## 用途

壁纸色调处理工具，对输入壁纸图片计算平均色调并叠加半透明着色层，生成适合桌面环境的背景图片。它加载输入图片，将其缩放至 16×16 像素以计算平均颜色，通过色调调整算法处理色调，再叠加半透明着色矩形，最终输出处理后的背景图片。通过 `-o` 参数指定输出路径。该工具通常在用户更换壁纸或显示配置变更时由系统自动调用。

## 用法

`dde-pixmix [options] <input-file>`

## 参数

| 选项 | 说明 | 是否需要值 |
|------|------|------------|
| `-h, --help` | 显示命令行帮助 | 否 |
| `-v, --version` | 显示版本信息 | 否 |
| `-o, --output <path>` | 输出处理后的背景图片路径 | 是 |

## 位置参数

| 参数 | 说明 |
|------|------|
| `input-file` | 输入壁纸图片路径（必填） |

## 使用示例

```bash
# 对输入壁纸进行色调处理并输出到指定路径
dde-pixmix -o /home/user/.cache/deepin/wallpaper-mixed.jpg /home/user/Pictures/wallpaper.jpg

# 查看版本信息
dde-pixmix -v
```

> 注意：`dde-pixmix` 是图形化壁纸处理工具，需要图形显示环境（X11/Wayland），在无 DISPLAY 的终端中运行会失败。
