# 主题自定义、安装与应用

用于制作主题包、修正视觉素材以及安装和应用自定义主题。已有主题或单项设置直接使用 [Appearance1](dbus/org.deepin.dde.Appearance1.md)，无需重新制作资源。

## 1. 确定交付范围，尽早检查执行条件

- 区分生成文件、安装到用户资源目录、应用到桌面。用户只要求生成时交付可用素材与使用说明；已要求应用时继续完成安装、设置和验证，不重复询问普通可逆操作。
- 根据用户要求确定壁纸、图标、配色、应用明暗外观及主题包格式。未指定的光标、音效、字体、缩放和锁屏背景不自动纳入；仅有审美细节不明确时，可说明合理假设继续制作。
- 先做与任务有关的最少探测：目标系统和组件版本、会话实现、资源格式；涉及安装或应用时，再检查目标目录可写性、桌面会话总线及接口能力。权限或执行环境发生变化后重新检查，不沿用先前受限的结论。
- 按需读取参考资料，复用探测结果。切换设置不需要枚举所有主题文件；制作素材也不需要预先加载全部桌面接口或开发资料。

## 2. 优先复用，先完成可用的小样

- 根据目标机已有主题的组织方式制作所需资源。优先复用可用的应用明暗外观与光标，通过图标主题继承补齐未覆盖的名称；“自定义主题”不意味着必须重做每一层。
- 插画、照片等壁纸可使用现有的图像生成或编辑工具；已有 SVG、图标系统优先在原格式中修改。记录实际图片分辨率与比例，给桌面图标和锁屏时钟等用途留出合适空间，不把插值放大称作原生高分辨率。
- 先制作一张壁纸及少量代表图标，比较效果后再扩展。只有用户要求或目标应用实际需要时，才增加多套变体、额外格式、安装恢复脚本或完整打包流程。
- 使用已有转换和缓存工具；需要 DCI 时先查目标机可用工具，必要时按 `dtk-development` 的图标资料处理。缺少转换工具时，先验证现有格式是否可用，避免直接转入框架源码研究或自写转换器。

## 3. 校准可见主体，而非只看画布

- 将自定义图标和目标主题的同类图标渲染到相同显示尺寸，比较透明通道中的主体边界、留白比例和视觉重心；不要把低透明度阴影当作主体。对文件夹、圆形和方形图标分别校准，避免统一缩放造成裁切或轮廓失衡。
- 在实际使用尺寸和当前显示缩放下并排查看，兼顾亮暗背景中的识别度、描边清晰度、装饰徽标和阴影边缘。图标“能解码”只是文件检查，不能证明视觉大小一致。
- 扩展整套图标前通过代表样本检查。修改后同步更新已有的 SVG、PNG、DCI 等交付版本、预览和压缩包，防止源文件、安装副本与交付包不一致；没有这些交付物时不必额外新增。

## 4. 按目标机格式安装，保留恢复条件

- 原生全局主题以目标机同版本已安装主题的 `index.theme` 为样本，核对 `[Deepin Theme]`、默认和深色分组、预览及资源引用；图标主题核对名称、目录声明、继承和实际应用所用的图标名。不要仅改文件后缀就宣称支持某种主题包格式。
- 常见用户目录包括 `~/.local/share/deepin-themes/<主题标识>/`、`~/.local/share/icons/<主题标识>/` 和 `~/.local/share/dsg/icons/<主题标识>/`，但应以部署版本支持的扫描目录及资源发现结果为准，不假设任意自定义数据目录都可被识别。
- 使用独立主题标识，只更新本主题所属资源，不覆盖系统主题或无关目录。替换已安装的自定义素材前保留旧版本；仅备份配置值不能恢复被覆盖的图像文件。
- 改动前记录对应原值与作用范围，包括目标用户、工作区和显示器。应用全局主题前检查它会联动修改的字段；用户只要求图标或壁纸时使用对应单项接口，避免连带修改其他设置。锁屏或登录背景单独按用户要求处理。
- 先完成资源安装，再用 Appearance1 的 `List` / `Show` 确认目标资源被识别；使用返回的主题标识调用 `Set`。缓存刷新按目标组件支持的方式执行；不要为刷新图标强制终止桌面进程或要求注销。

## 5. 验证生效，处理失败

- **素材检查：** 检查主题配置、路径引用、图片解码、图标透明度与视觉对比；隔离目录安装只能证明复制和结构可用。
- **桌面检查：** 回读对应的 `GlobalTheme`、`GtkTheme`、`IconTheme`、活动色等实际修改项；壁纸按目标工作区和显示器读取，不用 daemon 的 `Background` 记录代替实际工作区壁纸。按可用能力查看实际界面或截图，尤其检查自定义图标与继承图标混用的效果。
- **失败处理：** 区分文件系统只读、会话总线不可访问、资源未发现和应用后回读不符。先定位失败阶段，不反复重试同一受限路径，也不把工具环境限制归因于桌面功能故障；仅使用获授权且实际可用的执行入口。
- 已发生部分修改时，核对当前状态，按原作用范围恢复本次改动并验证；保留恢复失败的证据和备份。全局主题切换可能影响多个设置，不能承诺只写回一个主题名就恢复全部自定义值。
- 报告分别说明文件生成、资源安装和设置生效的结果，以及已验证项、未验证项、恢复方法。无法直接应用时保留可用交付物，给出最少的后续步骤，不将计划、模拟结果或命令返回成功写成实际生效。
