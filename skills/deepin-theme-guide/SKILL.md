# deepin 主题编写指南

通过选择已有的应用样式、图标主题、字体和光标主题，编写一个新的 DDE 全局主题。主要工作是组合资源、填写配置、组织目录，使这套主题可以在控制中心被选择。

图标主题、字体和光标主题各自遵循对应资源规范；这里负责选择和引用它们。完整主题可以依赖已安装的资源包，不要求把每类资源重新制作或复制一份。

## 默认工作流程

1. **确定主题身份与范围。** 使用独立的主题 ID，确定显示名称、亮暗模式，以及用户指定的配色、壁纸和资源偏好。默认编写亮暗两个配置分组。
2. **选择已有资源。** 读取 [资源选择](references/resources.md)，从可用集合确定应用样式、图标、光标、标准字体和等宽字体。已有的用户资源清单可以直接使用；需要查询时，使用 `deepin-desktop-environment` Skill 的 Appearance1 外观服务。
3. **编写主题配置。** 读取 [配置与存放规则](references/global-theme.md)，以 [index.theme 模板](assets/index.theme) 为起点，填写所选资源、字号、亮暗活动色和壁纸引用。模板名称是示例，替换成已选定的有效值。
4. **组织主题目录。** 在工作目录准备 `index.theme`、预览以及需要随主题提供的壁纸；复用已安装资源时保留有效引用，并列明依赖。用户要求安装时，部署到对应的用户或系统主题目录。
5. **交付完整组合。** 给出主题目录、资源选择清单、安装位置及亮暗选择值。确认每项引用都有资源或明确的依赖；需要实际选择主题时，使用 `deepin-desktop-environment` 的 Appearance1 服务。

用户只询问编写规则时，按所问部分解释；用户要求创建主题时，应落实为主题配置和目录，不停留在兼容性分析。

## 一套主题需要确定的内容

| 内容 | 组合方式 |
| --- | --- |
| 主题身份 | 目录 ID、显示名称、说明、预览 |
| 应用外观 | 为亮暗分组分别选择可用的 `AppTheme`，确定对应活动色 |
| 图标 | `IconTheme` 引用已有图标主题名称 |
| 光标 | `CursorTheme` 引用已有光标主题名称，可与图标名称不同 |
| 字体 | 用 `StandardFont`、`MonospaceFont`、`FontSize` 组成字体方案 |
| 壁纸 | 为亮暗分组指定图片，可以相同；锁屏背景按需要配置 |
| 可选窗口外观 | 根据目标桌面支持配置圆角、不透明度等参数 |
| 资源依赖 | 列出复用的资源名称、所需资源包及随主题提供的文件 |

字体方案通过字体族和字号表达，没有统一的 `FontTheme` 字段。已有图标、字体和光标资源继续放在各自目录中，全局主题配置负责选用它们。

## 按需处理应用样式

复用已有应用样式时，保留其对应的亮暗外观。根据需要分别读取以下文档，普通资源组合任务无需加载它们。

| 需要处理的内容 | 文档 |
| --- | --- |
| 理解设置如何发布、Qt/GTK 如何使用主题、亮暗与刷新机制及工具包支持范围 | [主题生效机制](references/theme-mechanism.md) |
| 为主题补充 GTK 亮暗样式、映射配色、组织样式资源并接入全局主题 | [GTK 主题适配](references/gtk-adaptation.md) |

服务能力按 `deepin-desktop-environment` 的 Skill 名称和相关服务名称引用，具体接口用法由该 Skill 提供。
