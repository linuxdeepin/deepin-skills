# 请求格式与主题搭配

## 请求字段

请求是 UTF-8 JSON 对象，未知字段会被拒绝。只提交用户要修改的字段，省略字段保持不变。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `wallpaper` | string | 已存在的本地图片绝对路径或 file:// URI；PNG/JPEG/WebP/BMP，最多 128 MiB |
| `monitor` | string | 壁纸目标显示器的真实名称，如系统显示设置中的 eDP-1；省略为主显示器 |
| `icon_theme` | string | 当次 `catalog` 返回的 `icon[].id`，原样使用 |
| `cursor_theme` | string | 当次 `catalog` 返回的 `cursor[].id`，原样使用 |
| `cursor_size` | integer | 16–128；实际是否支持及效果以接口读回和桌面观察为准 |
| `accent_color` | string | #RRGGBB；新接口浅色活动色，旧接口单个活动色 |
| `accent_color_dark` | string | #RRGGBB；新接口深色活动色，必须与 accent_color 一同提交 |
| `reason` | string | 可选的简短搭配理由，不作为命令执行 |

支持在文件路径和主题 ID 中使用空格、中文、引号；脚本使用参数数组调用 gdbus，不解释 shell。但写请求文件时仍应使用文件工具或正确的 shell 引用，避免 Agent 自己拼出会执行命令替换的 shell 文本。

下面仅展示格式。`bloom` 是否可用必须先以目标机器 catalog 确认，壁纸路径也必须替换为真实文件：

```json
{
  "wallpaper": "/home/实际用户名/Pictures/实际壁纸.png",
  "icon_theme": "bloom",
  "cursor_theme": "bloom",
  "cursor_size": 32,
  "accent_color": "#406A91",
  "accent_color_dark": "#79A7D2",
  "reason": "已有山水壁纸搭配低饱和蓝色，保留清晰的图标与光标轮廓"
}
```

仅修改两种模式活动色的请求无需主题素材：

```json
{
  "accent_color": "#406A91",
  "accent_color_dark": "#79A7D2"
}
```

## 选择规则

优先考虑用户偏好、素材真实性、可见性与整体协调。可从壁纸中选择少量低干扰色，主色用于活动色，复杂纹理避开常放桌面图标的位置。光标尺寸应结合缩放比例和用户视力偏好；不要把大尺寸默认应用到所有用户。

“图标颜色统一”不保证第三方应用自己的图标会跟随系统变化；“护眼”只表达视觉偏好，不能承诺医疗效果。没有视觉输入时不要声称已分析壁纸像素、对比度或截图。

新接口把活动色表示为 `浅色,深色`。只给 `accent_color` 时脚本保留原深色值；想在当前深色桌面明显看到变化，应同时指定 `accent_color_dark`。原颜色对无法解析时拒绝修改，以保留完整恢复信息。

## 素材边界

这个包支持主题组件组合、网络壁纸下载、本地图片应用与恢复，不包含第三方主题包下载或安装脚本、图像生成账户。图片文件头检查用于过滤明显错误的文件，不是完整图像解码或视觉质量评估。

壁纸按 [wallpaper.md](wallpaper.md) 搜索并下载最适合用户偏好与屏幕的图片；用户已确认自动挑选、下载和应用时连续完成，不以明确版权许可为个人桌面使用的前置条件。需要新主题包时使用 `theme_pack.py create` 统一封装受支持的基础图标、光标、壁纸和屏保素材；任意一张图标或光标图片仍不等于可安装主题，必须具备目录、尺寸、状态、热点与元数据。生成规范见 [package.md](package.md)，光标加载与同步见 [cursor.md](cursor.md)。

切换整套全局主题、字体、登录界面、锁屏背景、窗口圆角和性能策略不在本包的执行范围中。不要为完成四项外观修改而隐式改变这些设置。
