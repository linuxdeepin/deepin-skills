# 如何选择并组合已有资源

新建全局主题时，先确定要使用的已有资源，再把它们的名称写进 `index.theme`。图标主题、字体和光标主题本身的制作由各自的规范负责，本页只说明如何选用。

## 获得可选资源

使用 `deepin-desktop-environment` Skill 的 Appearance1 外观服务，查看可用全局主题、应用样式、图标、光标、标准字体与等宽字体。需要沿用某套基础主题时，读取其现有组合，保留可用的资源选择，再修改新主题需要变化的项。

用户已经提供可靠的资源清单时，可以直接据此填写。用户指定了资源名称时优先采用；未指定时可沿用选定基础主题的资源组合，避免凭主题名称猜测资源存在。

| 要选择的资源 | 从哪里选择 | 写入全局主题的内容 |
| --- | --- | --- |
| 亮、暗应用样式 | 可用应用样式，或基础全局主题的亮暗分组 | 两个分组各自的 `AppTheme` |
| 图标主题 | 可用图标主题列表 | `IconTheme` 使用资源名，例如已安装的 `bloom` |
| 光标主题 | 可用光标主题列表 | `CursorTheme` 使用光标资源名，独立于图标选择 |
| 标准字体 | 可用标准字体列表 | `StandardFont` 使用完整字体族名 |
| 等宽字体 | 可用等宽字体列表 | `MonospaceFont` 使用完整字体族名 |
| 字号 | 用户偏好或基础主题字号 | `FontSize`，以 point 表示 |
| 壁纸、预览 | 用户图片、已有主题图片或系统壁纸资源 | 图片文件引用，而不是主题名称 |

服务使用按 Skill 名称和 Appearance1 服务名称引用，具体接口由 `deepin-desktop-environment` 提供。

## 选择结果如何填写

- **应用样式：** 全局 ID 与样式名独立。例如新的 `aurora` 主题仍可使用已有 `deepin`、`deepin-dark`。亮暗名称以实际可用资源为准，不要求为新全局 ID 另建一套样式。
- **图标：** 填写图标主题资源名，不填写图片路径或某个单独图标名称。所选图标主题及其依赖应已可用，内部内容继续遵循图标主题规范。
- **光标：** 从光标列表单独选择，即使与图标使用相同名称，也要分别填写两个字段。使用已有光标主题即可，无需在新全局主题中重新制作光标文件。
- **字体：** 填写字体族名，不填写字体包名、字体文件路径或字体显示样例。标准与等宽字体共同形成字体方案，无需新增“字体主题”目录或 `FontTheme` 字段。
- **壁纸与预览：** 可以复用已有图片；随主题分发的图片放在主题目录内，已有持久资源可保留路径引用。

亮暗共用的图标、光标和字体只写在默认分组即可，暗色分组通过字段继承使用它们。需要两套不同资源时，在暗色分组另写对应名称。

## 已有资源放在哪里

| 资源 | 常见用户位置 | 常见系统位置 |
| --- | --- | --- |
| 应用样式 | `~/.local/share/themes/<样式名>/` | `/usr/share/themes/<样式名>/` |
| 图标主题 | `~/.local/share/icons/<图标主题名>/` | `/usr/share/icons/<图标主题名>/` |
| 光标主题 | `~/.local/share/icons/<光标主题名>/` | `/usr/share/icons/<光标主题名>/` |
| 字体文件 | `~/.local/share/fonts/` | `/usr/share/fonts/` |
| 壁纸 | 已有持久图片路径，或新主题内的壁纸目录 | 例如 `/usr/share/wallpapers/deepin/` |

这些是常见位置；选用时以服务能识别、目标用户能使用的资源为准。新全局主题的目录位置见 [配置与存放规则](global-theme.md)。

复用资源时不必复制到新的全局主题目录，也不需要分别制作 Qt 版与 GTK 版图标、字体和光标。只依赖制作者个人目录的资源适合该用户使用；面向其他用户或机器分发时，应改为可安装的资源包依赖或随包提供合法资源。

## 保存一份组合清单

在制作结果中列明应用样式的亮暗名称、图标名称、光标名称、两个字体族、字号、壁纸与预览路径。对外部资源同时注明提供它们的资源包或部署要求。

名称声明不会安装资源。某款字体缺失时可能显示替代字体，因此应确认所选字体族确实可用；某个图标或光标主题被其他主题继承，也不等于可以省略它的资源依赖。

完成的组合应满足：默认分组所需资源明确、暗色覆盖项明确、所有图片引用有效、所有复用资源能够在目标安装环境中获得。已有 GTK 样式不满足目标配色时，读取 [GTK 主题适配](gtk-adaptation.md)；需要了解 Qt/GTK 如何使用这些设置时，读取 [主题生效机制](theme-mechanism.md)。
