# 图标、光标和屏保素材限制

## 图标

生成器遵循 Freedesktop 图标主题的基本目录：`index.theme` 声明主题名、继承链和目录；当前输出使用 `scalable/*` 的 SVG。内置图标使用 64×64 设计网格，提供 16/24px 的简化稿与 scalable 稿；不同系列使用独立的材质和色族。安装后应用是否即时刷新由应用自身决定，不能通过脚本强制重启所有应用。

主题名是目录 ID，不能含空格或逗号；主题显示名可以包含空格。`bloom,hicolor` 是回退链，未生成的应用图标不会自动变成新画风。新版会扫描目标应用，desktop 模式加入常用位置、状态、设备、MIME 和动作名称，base-theme 模式进一步枚举基准主题。每个名称都生成文件，但内置稿不等于品牌 Logo；未知名称的保留素材与占位图均单列。精细设计、绝对路径处理、GTK/Qt 实际来源检查及范围边界见 [icons.md](icons.md)。

## 光标

源文件是 SVG，生成器使用 `rsvg-convert` 光栅化为 PNG，再由 `xcursorgen` 或内置标准 ARGB 写入器编译。配置中的每行包含：名义尺寸、热点 x、热点 y、图片路径；每种状态的配置包含多档尺寸。默认 24/32/48 档，热点随尺寸缩放。当前使用静态稿；自定义形状通过 cursor.overrides 的 SVG 与热点输入，动画多帧尚未提供。编译后仍需观察热点和状态切换。格式、原生库加载与热更新诊断详见 [cursor.md](cursor.md)。

`left_ptr`、`hand1`、`text`、`watch` 等状态必须覆盖常见交互，否则系统会回退到其他主题中的状态，造成风格不一致。编译失败、工具不存在或生成主题只有 SVG 源文件时，状态必须标记为未完成；不能只因为文件存在就报告“鼠标样式已替换”。

生成器还复制 `pointer/hand2`、`xterm`、`wait/progress`、`move` 等常用别名，缺失状态继承 `bloom`。默认包含垂直/斜向缩放、禁止、帮助、抓取等 15 种状态；旋转及应用私有状态仍可能回退。

## 屏保

图片屏保目录只接受 PNG/JPEG/BMP，单文件最多 128 MiB；Deepin 自定义屏保配置的轮播间隔范围是 3–3600 秒。生成器只复制图片并写 `config.json`，激活通过 `dde-dconfig` 写入 `org.deepin.screensaver/org.deepin.customscreensaver` 的 `slideshowPath`、`intervalTime` 和 `playMode`，同时切换 `currentScreenSaver`。

目标系统还必须安装 `deepin-screensaver` 和 `deepin-custom-screensaver` 组件。图片屏保的读回值只能证明配置已经写入，不能证明锁屏后每张图片都能显示；应在目标机器实际预览。屏保的锁定、唤醒和安全策略不由主题包隐式修改。

不同系统的 `dde-dconfig get` 可能把数字序列化为 JSON 数字或数字字符串，适配器会将间隔与播放模式统一为整数。写入时传递 CLI 原始参数，不把路径额外包成带引号的 JSON 字符串。

## 壁纸

壁纸不在技能内绘制。用户确认自动选图、下载和应用后，按主题契合度、构图和画质搜索高清素材，用 `wallpaper_source.py` 下载：先读取当前屏幕分辨率，要求宽高均不小于屏幕（不需要完全相等），宽高比只做“尽量相近”的提示而不阻止使用，下载后记录 URL、来源页和 SHA-256，作者与许可已知则记录、未知留空。个人桌面使用不以明确版权许可为前置条件。生成器只接收本地文件，不联网；拒绝非 HTTPS、超大文件、伪后缀和需要放大的图片。

本地素材（用户提供、浏览器下载或已购买）仍可直接传给 `create`；带 `.source.json` 侧车时来源记录会随包安装。文件头检查能拦截明显的错误后缀，但不能替代完整的图像质量和内容审查。完整流程见 [wallpaper.md](wallpaper.md)。

安装会通过原生接口将壁纸加入控制中心自定义壁纸库；生成文件名含内容摘要，避免覆盖同 URI 后桌面继续显示旧图。原生路径与可见性验证见 [control-center.md](control-center.md)。

## 模型生成的边界

模型适合生成设计规范、SVG 参数、图标名称清单、颜色和轮播配置；本地脚本负责解析、限长、文件类型、目录边界和编译。任何模型输出都先进入 JSON 规范，不能直接进入 shell。生成脚本不执行包内脚本、桌面文件的 `Exec` 字段或任意二进制；动态屏保另行审核。
