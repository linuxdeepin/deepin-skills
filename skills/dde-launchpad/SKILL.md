# dde-launchpad

dde-launchpad 是 DDE 启动器组件，通过 Session 总线提供启动器的显示、隐藏、切换和模式控制能力。

## D-Bus 接口

### 启动器控制

提供启动器的显示、隐藏、切换和模式控制能力。
