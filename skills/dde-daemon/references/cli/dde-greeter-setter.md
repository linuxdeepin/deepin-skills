# dde-greeter-setter 命令参考

登录界面设置工具，用于在 LightDM 登录阶段配置 greeter 相关参数。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-daemon` |
| 安装路径 | `/usr/lib/deepin-daemon/dde-greeter-setter` |
| DDE 角色 | 登录界面的配置数据提供工具 |

## 用途

登录界面设置工具，用于在 LightDM 登录阶段配置 greeter 相关参数。它在登录过程中运行，为 deepin greeter 提供配置数据支持，不提供 flag 参数。
