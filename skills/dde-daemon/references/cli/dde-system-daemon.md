# dde-system-daemon 命令参考

DDE 系统守护进程，是 DDE 桌面环境中运行在系统级别的核心后台服务。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-daemon` |
| 安装路径 | `/usr/lib/deepin-daemon/dde-system-daemon` |
| DDE 角色 | 系统级核心后台服务，管理硬件和系统模块 |

## 用途

DDE 系统守护进程，是 DDE 桌面环境中运行在系统级别的核心后台服务。它负责管理多个系统级模块（网络、蓝牙、电源、声音、账户），通过 DBus 提供系统管理接口。该守护进程在系统启动时自动运行，是 DDE 桌面环境正常运作的基础服务。
