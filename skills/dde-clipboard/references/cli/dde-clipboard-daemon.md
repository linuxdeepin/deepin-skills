# dde-clipboard-daemon 命令参考

DDE 剪贴板守护进程，负责管理剪贴板历史记录和剪贴板事件监听。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-clipboard` |
| 安装路径 | `/usr/bin/dde-clipboard-daemon` |
| DDE 角色 | 剪贴板管理系统的后台守护进程 |

## 用途

DDE 剪贴板守护进程，负责管理剪贴板历史记录和剪贴板事件监听。它在用户会话中后台运行，通过 DBus 为剪贴板管理器提供数据存储和检索支持。该守护进程在会话启动时自动运行，一般不需要用户直接运行。
