# dde-clipboard 命令参考

DDE 剪贴板工具，提供图形化的剪贴板历史管理界面。

## 基本信息

| 字段 | 值 |
|------|------|
| 所属包名 | `dde-clipboard` |
| 安装路径 | `/usr/bin/dde-clipboard` |
| DDE 角色 | 用户使用的剪贴板管理 GUI 工具；由会话管理自动启动 |

## 用途

DDE 剪贴板工具，提供图形化的剪贴板历史管理界面。它记录用户复制/剪切的内容历史，允许用户查看、搜索和重新粘贴之前复制的内容。支持包括文本和图片在内的多种内容类型。该工具通常由 DDE 会话管理自动启动，也可以通过命令行手动启动，`--always-show` 选项用于调试时保持窗口不自动隐藏。

## 用法

`dde-clipboard [options]`

## 参数

| 选项 | 说明 | 是否需要值 |
|------|------|------------|
| `-h, --help` | 显示命令行帮助 | 否 |
| `-v, --version` | 显示版本信息 | 否 |
| `--always-show` | 显示后永不自动隐藏 | 否 |

## 使用示例

```bash
# 正常启动剪贴板管理界面
dde-clipboard

# 启动并保持窗口不自动隐藏（用于调试或持续查看剪贴板历史）
dde-clipboard --always-show

# 查看版本信息
dde-clipboard -v
```

> 注意：`dde-clipboard` 是图形化剪贴板管理工具，需要图形显示环境（X11/Wayland），在无 DISPLAY 的终端中运行会失败。
